# Math Notes

Personal mathematics learning notes maintained through Obsidian and GitHub.

The vault is organized around four kinds of notes:

- `Sources/` — textbooks, GPT teaching chapters, papers, videos, and other source material.
- `Concepts/` — mathematical objects, definitions, relations, interpretations, and evolving understanding.
- `Problems/` — questions from textbooks, engineering work, cryptography, radar, algorithms, and other contexts.
- `Tools/` — compressed, reusable mathematical ideas and problem-solving patterns.

The intended learning loop is:

`Source / Problem -> expand understanding -> verify -> compress -> reusable Tool -> new questions`
